# StageLab V3｜哈姆雷特：舞台流变

用《哈姆雷特》的连续剧情与四个真实制作，认识镜框式、中心／环绕式、伸出式三种核心舞台形制。

## 打开方式

**推荐：用 Chrome 或 Edge 打开 `StageLab_Hamlet_V3_单文件.html`。** 照片、字体、样式、脚本均已内嵌，可以单独复制，断网播放，无需安装依赖。

源码包解压后也可直接打开 `index.html`，但需要保留旁边的 `src`、`assets`、`productions` 文件夹。Windows 可双击 `start_hamlet_v3.bat`，它会打开本地网页；课堂期间保留启动窗口，关闭窗口即可停止本地服务。若服务不能启动，脚本会尝试直接打开 `index.html`。

页面需要 WebGL2。若浏览器提示不支持，请使用开启图形加速的 Chrome 或 Edge。资料中的外部来源链接需要联网；课堂动画和随包照片不需要联网。

## 这一版的教学重点

原顺序保持为 **Barbican 2015 → Royal Exchange 2014 → Young Vic 2011 → Globe 2018 → Barbican 结尾**。

- **Barbican：镜框式舞台。** 台口、单侧观看、正面构图与纵深。后段回看同一形制下的舞美变化。
- **Royal Exchange：中心／环绕式舞台。** 多方向观看、遮挡、地面与上空的使用。
- **Young Vic：可变式剧场。** 这是场所补充，本次主表演区仍为伸出式；环境化入场不等于第四种舞台。
- **Globe：伸出式舞台。** 三侧观看、与后台相连，及戏中戏的多层观看关系。

舞台形成后，左侧出现简要知识卡，动画继续。点击「展开舞台知识」「查看场所补充」或右侧四个知识入口，打开详细卡片并暂停剧情；关闭时恢复打开前的播放状态。详细卡片包含定义、结构、特征、简短历史、典型运用、设计时需要核对的关键尺寸、真实制作及来源。尺寸表列出需要核查的参数，不提供未经核实的场馆数值。

界面统一为半透明圆角面板；普通旁白与人物对白固定在底部，中文在上、英文在下，角色姓名缩小显示。少量关键台词仍附着在建筑或舞台上。「丹麦是一座监狱」标注为文本回声，不作为设计师原话。

## 课堂操作

- 点击提示台词或亮起的黄色观众小人，推进互动节点；Enter 可代替点击。其余剧情自动播放。
- 拖动沙盘旋转，滚轮缩放；空格暂停／继续。
- 左右箭头切换段落，R 重播当前段，数字 1–7 直接跳段。
- I 打开使用说明，A 打开当前制作的知识与资料，Esc 关闭详细卡片。
- 打开详细卡片会暂停；若原本已暂停，关闭后仍保持暂停。
- 地址可加 `?scene=5&auto=1&speed=2`，用于跳段、自动触发互动、倍速演示；`?q=low` 可降低画质。正常课堂使用不必设置。

## 真实制作与教学模型

照片、来源与资料支持的观察，和沙盘的几何教学模型分别标明。各制作之间的连续拆台、重组是本网页的叙事手段，原演出中没有发生。人物精确路线、座位数量及局部建筑尺寸属于示意，不能作为原演出的实测记录。

Young Vic 的入场走廊不是官方平面；Royal Exchange 由同一演员分饰鬼魂和克劳狄斯，模型为叙事使用两个小人，鬼魂按当年评论改为白衣。Globe 2018 的伶人先演哑剧再退出有现场记录支持；后续人物位置用于解释「谁在看谁」，并非实录。悲剧结局是原作剧情概述，不代表 Globe 2018 的实际调度。知识卡里的平面小图是三种形制的关系示意，不是场馆施工图。

Barbican 照片来自 Es Devlin 官方图集，Royal Exchange 照片来自 Amanda Stoodley 作品集，Young Vic 为 British Theatre Guide 所配制作照片，Globe 为 Globe Player 官方预告封面。Royal Exchange 剧照并非鬼魂场面的逐帧记录；Globe 封面是人物特写，不能证明剧场形状。建筑与制作资料在各卡片中单独提供可查链接。图片权利归原作者或机构，保留原署名和来源。字体为本页字符子集，原 OFL 许可见 `assets/fonts/`。

## 修改入口

- `productions/data.js`：制作档案、`stageNotes` 知识卡、`teachingSources` 来源、照片与复原边界。
- `src/story.js`：连续剧情、舞台变形、互动触发。
- `src/world.js`、`src/figures.js`：空间构件、人物、服饰与王冠。
- `src/ui.js`、`src/text.js`、`src/style.css`：卡片、图示、字幕和界面。
- `tools/build_standalone.py`：运行 `python tools/build_standalone.py`，重新生成离线单文件。需要 Python，无第三方依赖。
- `tools/subset_fonts.py`：大量新增中文时可重新生成字形子集，使用方法见脚本说明，需要原字体和 fontTools。

这是单页 WebGL2 教材，运行不需要编译。修改多文件源码后，请重新生成单文件，避免打开旧副本。
